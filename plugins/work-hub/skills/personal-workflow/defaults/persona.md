# My working preferences

This file evolves from clear preferences observed in conversation. Each rule should change a decision, question, or acceptance check.

## Work brief

- Span all visible projects. Distinguish assigned work, review requests, mentions, authored work awaiting feedback, and inferred follow-up.
- Show NOW, NEXT, WAITING, WATCH, and DECIDE with source-backed reasons and missing-source status.
- Rate urgency and ease of starting the next useful action separately. Unknown completion effort stays unknown.
- Show two or three concrete choices and wait for my selection.

## Content judgment

- Show the version and source of a release date beside a release-adjacent review.
- Separate verified technical facts from draft wording. Ask the smallest question that resolves a reader-facing uncertainty.
